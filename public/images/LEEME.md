# Fotografías de The Barber's

Copia aquí las fotos con estos nombres y la web las mostrará sola (sin tocar código).
Hasta entonces, cada hueco enseña un panel oscuro con textura.

| Archivo                          | Dónde aparece                        | Medida recomendada |
| -------------------------------- | ------------------------------------ | ------------------ |
| `hero.jpg`                       | Portada (barbero trabajando)         | 1920 × 1200 px     |
| `nosotros.jpg`                   | Sección "Más que un corte"           | 1200 × 1500 px     |
| `servicio-cortes.jpg`            | Tarjeta "Cortes de pelo"             | 1200 × 900 px      |
| `servicio-degradados.jpg`        | Tarjeta "Degradados"                 | 1200 × 900 px      |
| `servicio-barba.jpg`             | Tarjeta "Arreglo de barba"           | 1200 × 900 px      |
| `servicio-corte-barba.jpg`       | Tarjeta "Corte y barba"              | 1200 × 900 px      |

- Formato: JPG o WebP (si usas WebP, cambia la extensión en `src/config/site.ts`).
- Peso: idealmente por debajo de 300 KB cada una (squoosh.app las comprime sin perder calidad visible).
- Los textos alternativos y las rutas se editan en `src/config/site.ts` (`images` y `services`).
- Usa solo fotos propias o con licencia. No presentes imágenes de stock como fotos reales del local.
